# 🎮 地牢卡牌（aaa1024）

> 俯视角实时动作肉鸽（Roguelite）：在随机地牢中用近战与远程武器战斗，用卡牌改造武器行为，再把武器升级进化。
> 核心识别点：**武器就是卡组**。

技术栈：**Phaser 3 + TypeScript + Vite** ｜ 纯前端静态部署 ｜ 存档保存在浏览器本地 ｜ 目标平台：PC 浏览器

---

## 🕹️ 游戏介绍

一款俯视角实时动作肉鸽游戏。玩家进入一座不断变化的地牢，在房间中战斗、探索宝箱、收集卡牌与装备。

### 核心玩法：武器就是卡组

- **实时战斗**：刀剑、长枪、法杖、弓箭等近战与远程武器，提供挥砍、突刺、射击、蓄力、格挡等不同基础手感；
- **卡牌改造武器**：每张卡牌都会改变武器的攻击行为——让铁剑释放剑气、让长枪连续突刺、让法杖分裂弹幕、让盾牌反弹攻击，形成不同的战斗流派；
- **升级进化**：武器从普通形态逐步升级为更高阶的视觉与机制形态，让构筑不断成长；
- **蓄力弹反**：敌人蓄力时出现收缩预警圈，在圈完全变色的精准时机出手即可打断蓄力、打出硬直。

### 局内循环

```
选择路线 → 进入随机房间 → 战斗清怪 → 三选一奖励 / 升级进化 / 商店
      → Boss 战 → 结算 → 下一关（难度递增）
```

- 1~10 关关卡循环 + 挑战模式，难度逐关提升；
- 新手教程关卡引导上手，可跳过；
- 三个独立存档槽，支持导出/导入；
- 已通关的历史关卡可回放刷材料；
- 锻造台：用局内材料解锁新武器与卡牌，调整起始构筑。

### 局外成长

将局内获得的材料带回锻造台，解锁新的武器和卡牌，为下一局打造更独特的构筑。

## 🚀 启动方法

### 方式 A：一键启动（推荐）

双击项目根目录的 **`启动游戏.bat`**

启动器会自动：检查 Node.js 环境 → 安装依赖（首次运行需联网）→ 寻找空闲端口 → 启动游戏并打印实际访问地址。

默认访问地址：**http://127.0.0.1:5173**（端口被占用会自动顺延到 5174/5175…）

### 方式 B：命令行手动启动

```bash
cd web
npm install     # 首次运行需要
npm run dev     # 启动开发服务器
```

然后浏览器打开 **http://127.0.0.1:5173**。

### 构建正式版本

```bash
cd web
npm run build       # 产出 web/dist/，可直接静态托管
npm run preview     # 本地预览构建产物（http://127.0.0.1:4173）
```

## ✅ 运行环境要求

| 项 | 要求 |
|---|---|
| Node.js | **≥ 20.19**（Vite 7 要求，推荐 20 LTS / 22 LTS） |
| 操作系统 | Windows（一键启动器）/ macOS / Linux（手动启动） |
| 浏览器 | 任意现代浏览器（Chrome / Edge / Firefox 等） |

> 提示：请先将整个文件夹完整解压，再双击 `启动游戏.bat`，不要在压缩包内直接运行。
> 若系统提示“禁止运行脚本”，请用命令提示符（cmd）双击运行 `启动游戏.bat`。
