# ADR-008：存档只保存局外数据

- **日期**：2026-10-24
- **状态**：已接受
- **决策人**：P1

## 背景

肉鸽的局内进度如果落盘，会出现「刷新就无敌/卡关」的漏洞；而锻造台进度必须持久化。

## 可选方案

- 方案 A：只存局外（材料、解锁、统计、图鉴、设置）
- 方案 B：存整局状态（可续关，但作弊与兼容成本高）
- 方案 C：不存任何东西

## 决策

选 A。`SaveData` 只含 `forge / stats / seen / settings`；局内状态由 `RunService` 持有，刷新即重开。

## 理由

1. 比赛场景 5–10 分钟一局，续关价值低；
2. 局外成长是长期留存的关键，必须稳；
3. 存档结构小，迁移与容错都简单。

## 后果

- 正面：不会出现续关作弊/坏档；存档代码只有 ~200 行。
- 负面：刷新丢当局进度（符合肉鸽预期）。
