# 🧭 决策记录（ADR — Architecture Decision Records）

> 记录团队做过的**重要决策**（为什么选这个方案，而不是那个）。防止“当初为什么这么定”的无限循环。

## ADR 是什么

每条记录是一份 **简短、具体、有时间戳** 的决策说明，包含：

- **背景** —— 当时面对什么问题
- **可选方案** —— 考虑过哪些选择
- **决策** —— 最终选了哪个
- **理由** —— 为什么选它
- **后果** —— 这个决定的代价/影响

```markdown
## 背景

...

## 可选方案

- 方案 A：...
- 方案 B：...

## 决策

选 A。

## 理由

1. ...
2. ...

## 后果

- 正面：...
- 负面/代价：...
```

编号规则：`ADR-001` 起顺序递增，文件名 `ADR-001-<slug>.md`。
