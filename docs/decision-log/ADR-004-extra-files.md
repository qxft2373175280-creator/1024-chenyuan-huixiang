# ADR-004：相对工作令目录的补充文件

- **日期**：2026-10-24
- **状态**：已接受
- **决策人**：P1

## 背景

工作令 §2.2 给了目录骨架，但落地时发现缺一些必要文件：结算页、角色数值文件、房间/局内状态系统、局外 UI 组件与素材预览。

## 可选方案

- 方案 A：按需新增文件，并在 ADR 记录（保持命名可预期）
- 方案 B：塞进已有文件（`GameScene` 会变成上千行，`ui/HUD` 混入菜单按钮）

## 决策

选 A，新增：

| 文件 | 归属 | 理由 |
|---|---|---|
| `src/scenes/ResultScene.ts` | P4 | 工作令只有 5 个场景，缺结算页 |
| `src/data/player.json` | P2 | 角色移动/冲刺/无敌帧必须数据驱动 |
| `src/systems/RoomSystem.ts` | P4 | 布局解析与地图生成独立于场景 |
| `src/systems/RunService.ts` | P4 | 局内金币/材料/击杀/计时需要单一持有者 |
| `src/gfx/UiKit.ts` | P1 | 局外按钮/面板/toast（P4 的 `ui/*` 是战斗 HUD，互不影响） |
| `src/gfx/debugAssets.ts` | P1 | `?debug=assets` 贴图预览页 |

## 理由

职责单一、文件名可预期；后续 P2/P3/P4 都能直接接管自己那份。

## 后果

- 正面：场景与系统边界清晰。
- 负面：与工作令目录有出入；已在《方案文档.md》§2.2 与附录 A 同步说明。
