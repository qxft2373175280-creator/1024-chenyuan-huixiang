# ADR-007：武器进化 = 替换为独立武器定义

- **日期**：2026-10-24
- **状态**：已接受
- **决策人**：P1

## 背景

进化要同时改变数值、外观、机制（如铁剑 → 魔焰剑获得剑气）。

## 可选方案

- 方案 A：进化后 `defId` 换成另一把武器定义（数据里写 `evolvesTo`）
- 方案 B：运行时给同一把武器叠「进化层」（buff 式修改 stats）
- 方案 C：在代码里 if (evolved) 做分支

## 决策

选 A。进化 = 换 def：数值/贴图/弹道全部来自新定义，卡槽 +1，已装卡牌保留，`evolved: true`。

## 理由

1. 数值与表现都在 JSON，策划能调；
2. 代码零分支，攻击流程完全复用；
3. 图鉴天然支持「进化形态」条目。

## 后果

- 正面：简单、可数据化、可扩展第二段进化。
- 负面：进化形态要各写一份完整武器数据；已由 `data:validate` 校验引用完整性兜底。
