## 一句话介绍（≤ 40 字）

把卡牌塞进武器里，让同一把铁剑变成毒刃、剑气风暴或处决机器——俯视角实时动作肉鸽。

---

## 三段卖点（每段 ≤ 60 字）

**1. 武器决定打法，卡牌决定流派**
铁剑三段连击、手枪点射、法杖三发扩散；10 张改造卡直接改数值与行为：分裂弹、旋风斩、长刃、毒刃、处决、连锁闪电……

**2. 局内进化，形态真的会变**
武器 Lv.1→3，满经验后三选一出现「进化」：铁剑→魔焰剑（挥砍带穿透剑气）、手枪→双管手枪（一次两发）、法杖→湮灭魔杖（四发扩散）。进化后卡槽 +1，已装卡全部保留。

**3. 局外成长，刷新不丢**
清怪掉材料 → 锻造台解锁蓝图与被动（体质强化/开刃/行囊）→ 下次开局更强。图鉴会记录你见过的武器、卡牌与敌人。

## 操作说明（字号小一点，放操作区）

| 操作 | 键位 |
|---|---|
| 移动 | `W` `A` `S` `D`（8 方向等速） |
| 攻击 | 鼠标左键（长按连发，朝鼠标方向） |
| 换武器 | `Q`（或 `1` / `2` 直接切主/副手） |
| 冲刺 | `Space`（残影 + 无敌帧，可穿弹幕） |
| 交互 | `E`（开宝箱 / 开商店 / 去下一间房） |
| 暂停 | `Esc`（继续 / 放弃本局） |

## 一局里会发生什么（流程条）

**进房 → 清怪 → 三选一装卡 → 升级/进化 → 宝箱/商店 → Boss（半血二阶段）→ 结算 → 再来一局**

- 6 个房间：3 个普通战斗房 + 1 个商店房 + 1 个精英房 + 1 个 Boss 房
- 5 套房间布局：空旷大厅 / 立柱回廊 / 十字中庭 / 环形市集 / 守卫长厅
- 5 种敌人：史莱姆（追）、喷吐者（远程）、冲锋兽（前摇冲撞）、重装守卫（精英砸地）、守卫长（Boss）

## 三个流派一句话（海报底部三列，可配截图）

| 流派 | 核心卡 | 打法 |
|---|---|---|
| **铁剑·旋风** | 旋风斩 + 长刃 | 360° 扫场，站桩抗压，靠吸血续命 |
| **手枪·弹幕** | 分裂弹 + 弹幕狂欢 | 5 发子弹洗地，击中连锁跳电 |
| **法杖·元素** | 毒刃 + 疫爆 | 上毒叠伤，中毒敌人死亡时爆炸传染 |
