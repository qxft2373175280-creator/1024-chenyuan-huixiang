## 二之二、蓄力弹反（PARRY-01）人工测试单

> 这节是 2026-10-25 新增玩法「蓄力攻击时机弹反」的真人测试项（**AI 不代勾**，对应待办 PARRY-004）。
> 玩法说明：《游戏玩法提案_给团队评审.md》§5.4 ｜ 技术：《技术方案与AI工作令.md》§2.9
> 前置：任意有**冲锋兽**的房间（第 1 房起就会出现），武器切到**铁剑**（手枪/法杖不能弹反是设计如此；铁剑进化成魔焰剑后仍可弹反）。

| # | 操作 | 预期现象 | 判定标准 | 结果 | 备注 |
|---|---|---|---|---|---|
| P1 | 站着不动，观察冲锋兽 | 怪物停下、以它为中心出现一个**大圈**，圈开始**缩小**并**从蓝变黄** | 圈确实在动（不是静止图）；圈心跟着怪物；圈从 375 收到 250（= 冲锋兽攻击范围） | ☐ | |
| P2 | 一直不攻击 | 圈缩到怪物身上并**变红**，短暂闪一下白光，然后怪物冲刺撞过来 | 白光能看见；变红到冲出来大约 0.2 s | ☐ | |
| P3 | 圈还是**黄色**时就出刀（早出手） | 只有普通伤害飘字，怪物**继续蓄力**，圈继续缩 | 不出现「弹反成功」提示；怪物没有被打断 | ☐ | |
| P4 | **圈变红的那一瞬**出刀（精准弹反） | 白光 + 冲击波 + 音效，怪物停在原地约 0.8 s，屏幕提示「弹反成功 · 反击窗口」 | 怪物**没有冲刺**；提示文字可读 | ☐ | |
| P5 | 弹反成功后 0.8 s 内继续输出 | 怪物不动，可以白打一套 | 硬直期间怪物不移动、不攻击 | ☐ | |
| P6 | 换成手枪，在窗口期开枪 | **不弹反**，只有普通伤害，怪物照常冲刺 | 不出现弹反提示 | ☐ | |
| P7 | 窗口过后（怪物已经锁死准备冲出）再出刀 | 不弹反，怪物照常撞过来 | 不出现弹反提示 | ☐ | |
| P8 | 让铁剑进化成**魔焰剑**，再弹反一次 | 仍能弹反成功 | 进化后不掉弹反（这次修复的重点） | ☐ | |
| P9 | 引 **2–3 只冲锋兽**同时蓄力 | 每个圈的内圈颜色不同（青/粉/紫），且各有一条短刻度连到自己那只怪 | 一眼能看出哪个圈属于哪只怪；3 只颜色必不相同；4 只以上刻度方向不同 | ☐ | |
| P10 | 连续重开场景 3 次，再弹反一次 | 没有重复的圈、没有残影、没有重复伤害 | 屏幕上每次只有 1 个圈；重开后第一次弹反正常 | ☐ | |
| P11 | 主观难度记录 | 10 次尝试的弹反成功率：____ / 10 | 40%–80% 之间算手感合适；<30% 偏难、>90% 偏简单 | ☐ | |
| P12 | 可读性记录 | 圈颜色变化是否看得清？是否挡住角色？ | 圈在地板层，角色始终在圈之上 | ☐ | |

> 调参提示（改完刷新即生效，不用改代码）：`web/src/data/parry.json`
> - 窗口太短 → 调大 `global.parryWindowMs`（注意必须 < `windupTotalMs`）
> - 蓄力太慢/太快 → 调 `global.windupTotalMs`
> - 硬直太短 → 调 `global.successStunMs`
> - 圈太大/太小 → 调 `enemies.json` 里冲锋兽的 `attack.rangePx`（圈半径 = 攻击范围 × 1.5 → × 1.0，固定规则，不做 per-enemy 覆盖）
> - 非近战武器想试弹反 → **不要**直接加进 `enabledWeaponIds`，`data:validate` 会直接报错（设计上首版只给近战）
