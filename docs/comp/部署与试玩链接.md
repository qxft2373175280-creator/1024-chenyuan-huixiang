## 3. 公开发布：三条路径（选一条，都需要一个凭据）

### 方案 A：itch.io（比赛最常用，推荐）

> AI 已把能自动化的部分做完了：butler 已安装、`npm run deploy:itch` 一键脚本已就绪、zip 已打包。

> [`itch.io上线操作指引.md`](itch.io上线操作指引.md)。

1. 网页端：itch.io → **Create new project** → *Kind of project* 选 **HTML**
2. *Uploads* 传 `web/dist-itch.zip`（已生成），勾选 **This file will be played in the browser**
3. 视口默认 `1280 × 768`（游戏原生分辨率），勾 Mobile 友好可开
4. 发布后把 `https://<用户名>.itch.io/<项目名>` 填进海报/二维码

自动化（需要 **butler** + itch.io API key）：

```bash
butler push web/dist <用户名>/<项目名>:html5 --userversion 0.3.0
```

### 方案 B：Vercel（最快拿到 https 域名）

需要 Vercel 账号与 **token**（https://vercel.com/account/tokens）：

```bash
cd web
npx vercel --prod --yes --token <VERCEL_TOKEN>     # 首次会问项目名
# 或指定静态目录：npx vercel deploy dist --prod --token <TOKEN>
```

### 方案 C：GitHub Pages（复用现有仓库，但**需要 push 授权**）

```bash
# 需要用户明确说「可以 push」后执行
cd web && npm run build && cd ..
mkdir -p docs/site && cp -r web/dist/* docs/site/   # 或改用 gh-pages 分支
git add docs/site && git commit -m "chore: 发布试玩页"
git push origin main
# 仓库 Settings → Pages → Source: main /docs/site
```

> ⚠️ 项目铁律：**未经明确授权不 push**。因此这条路线必须由用户点头。
