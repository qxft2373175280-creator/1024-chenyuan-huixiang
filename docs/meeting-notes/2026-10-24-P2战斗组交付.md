## 2. 怎么验证

```bash
cd web
npm install
npm run data:validate   # 6 个 JSON 引用/区间
npm run check           # tsc --noEmit + vite build
npm run dev             # http://localhost:5173 → 主菜单 → 进入战斗训练场
```

训练场快捷键：`F1` 史莱姆 / `F2` 喷吐者 / `F3` 冲锋兽 / `F4` 守卫长（Boss）/ `F5` 清场 / `R` 重开 / `Esc` 回菜单。
`?debug=1` 打开 Arcade 物理调试；`?debug=sandbox` 每 1.6s 自动刷史莱姆（压测用）。
