# 📝 会议纪要

> 记录每一次团队会议的核心结论与待办。命名格式：`YYYY-MM-DD-主题.md`

## 目录

| 日期 | 主题 | 纪要 | 状态 |
|------|------|------|------|
| — | 暂无 | — | — |

## 模板

```markdown
# YYYY-MM-DD 会议纪要：<主题>

- **时间**：YYYY-MM-DD HH:mm
- **参与人**：@xxx、@yyy
- **记录人**：@xxx

## 议题

1. ...

## 结论

- 决定 1：...
- 决定 2：...

## 待办（Action Items）

- [ ] @xxx：在 DD/DD 前完成 ...
```

## 要求

- 每次会议后 **24 小时内**由记录人提交
- 结论尽可能**具体、可执行**，不要写“讨论了一下”
- 重大决定同时在 `docs/decision-log/` 记录一笔 ADR，并互相引用
