# 01 - 游戏概念与核心玩法（GDD 初稿）

> 状态：**已确认方向**
> 类型：俯视角实时战斗（近战+远程）+ 肉鸽构筑
> 三要素融合：**元气骑士式实时战斗 × 卡牌改造 × 武器升级进化**

---

## 1. 一句话描述

> 在随机生成的地牢里，边打边捡卡，把一把白板铁剑/小手枪养到能劈开整关的传说形态 —— 死了重来，但收藏与锻造永久累积。

## 2. 核心设计：武器就是卡组

三个系统的咬合点：

```
元气骑士（操作/节奏/地图）
        ↓ 提供
   战斗手感 · 房间清怪 · 随机地图 · 双持换武器
        ↓
   武器（装备）＝ 卡组核心
        ↓ 被改造
卡牌（改造卡）→ 改变武器行为、定义流派
        ↓ 被喂养
装备升级（武器进化）→ 击杀攒经验，升级换形态
```

- **武器**决定基础攻击方式（铁剑/长枪/大锤/手枪/弓箭/法杖...近战远程都有）
- **卡牌**不抢战斗的戏，而是**装进武器/技能槽**，改造它的行为（附加毒、弹道改造、挥砍强化...）
- **升级**分两条线：局内武器击杀升级进化 + 局外锻造台永久成长

## 3. 一局循环（核心循环）

```
进房清怪 → 拿宝箱（卡/武器/材料）
   ↓
选卡装卡 → 改造武器，定流派
   ↓
武器升级进化 → 击杀攒经验，形态变化
   ↓
打 Boss / 精英 → 新材料 + 高阶卡
   ↓
变强 → 下一局 → 最终 Boss → 结算
```

## 4. 三个系统的具体规则

### 4.1 元气骑士式实时战斗（操作层）

- 俯视角，WASD + 鼠标/键攻击（后续可加手柄）
- **近战远程混搭**，武器分大类：

| 大类 | 示例 | 手感 |
|------|------|------|
| 近战 | 铁剑、长枪、大锤、双匕首 | 挥砍、突刺、蓄力重击、回旋 |
| 远程 | 手枪、霰弹、弓箭、法杖 | 点射、连发、蓄力抛射、弹幕 |
| 特殊 | 盾牌、回旋镖、陷阱 | 格挡、反弹、布设 |

- 房间制关卡，清完怪开宝箱进下一房
- 地图节点随机生成（普通房 / 精英房 / 宝箱房 / Boss 房 / 商店）
- 双持武器、可切换（近战主手贴身 + 远程副手补刀，不同武器配不同卡组）

### 4.2 装备升级（成长层，双轴）

**局内（一局内）**
- 武器有等级（Lv.1 ~ Lv.5），击杀敌人积累武器经验
- 升级时弹出强化选项（加攻速 / 加伤害 / 加元素 / 换形态）
- 满级或特殊条件 → 武器进化成更高阶形态：

```
近战进化：铁剑 → 魔焰剑 → 传说巨剑
远程进化：手枪 → 冲锋枪 → 霰弹冲击炮
法系进化：木杖 → 元素法杖 → 湮灭魔杖
```

**局外（永久成长）**
- 锻造台：消耗材料永久解锁武器图鉴、升级武器基础品质
- 解锁的角色 / 天赋树 / 初始卡组配置

### 4.3 卡牌（构筑层）

- 卡牌类型：**改造卡（装武器）**、**技能卡（装技能槽）**、**被动卡（角色常驻）**
- 武器有卡槽（如 3 个），装上后行为被改造：
  - 附加元素（火/毒/冰/电）
  - 攻击改造（弹道弹射分裂 / 挥砍范围连击 / 蓄力强化）
  - 数值强化（暴击、攻速、范围）
- 卡牌有稀有度（白/蓝/紫/金），高阶卡带组合特效
- 流派示例：
  - 毒爆流（淬毒武器 + 叠毒卡 + 扩散）
  - 弹幕流（远程 + 弹射 + 分裂）
  - 处决暴击流（匕首/大剑 + 暴击卡 + 处决）
  - 旋风近战流（大剑/长枪 + 攻速卡 + 吸血卡）
