## 建议大纲（游戏概念文档）

一份 GDD 通常至少包含：

1. **一句话描述** —— 30 秒内能让别人听懂这游戏是什么
2. **游戏类型** —— 动作 / 策略 / RPG / 休闲等
3. **核心循环** —— 玩家每秒做什么、每分做什么、每局做什么
4. **目标平台与输入方式**
5. **目标受众与商业模型**
6. **差异化卖点** —— 凭什么玩家选我们不选别人
7. **美术 / 音乐风格参考**
8. **风险点与未知项**

> 💡 第一次立项讨论建议：每人带 1~2 个游戏点子（一句话描述 + 核心循环），会上投票/合并，会后由负责人写 `01-game-concept.md`。
