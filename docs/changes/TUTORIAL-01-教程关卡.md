# TUTORIAL-01 新手教程关卡 —— 设计与改动文档

- 日期：2026-10-25 ｜ 状态：**自动验收通过**，真人手感未测
- 依据：蓝图第 1 轮工作令（教程关卡）
- 数据：`web/src/data/tutorial.json`（新增）｜ 类型：`web/src/core/tutorial-contracts.ts`（契约外增量）

## 1. 目标

新玩家「开始新游戏」后直接进教程，5 步分别学会：移动 / 攻击 / 冲刺闪避 / 卡牌三选一 / 蓄力弹反；
完成后写 `tutorialCompleted = true`、发首次奖励 20 材料，并自动进入第一关；随时可跳过（同样标记完成）。

## 2. 流程

```
开始新游戏（槽位选择）→ TutorialScene
  步骤1 移动（走到光圈，超时 10s 出箭头）
  步骤2 攻击（打史莱姆，超时 15s 提示左键）
  步骤3 冲刺（训练喷吐者发射弹道，靠近时 Space 冲刺；被打 3 次降难度）
  步骤4 卡牌（清 2 只史莱姆 → 真三选一 → 卡牌立即生效，HUD 卡槽 +1）
  步骤5 弹反（冲锋兽蓄力 → 红圈窗口内铁剑命中；失败 4 次自动把窗口 120ms 放宽到 200ms）
→ 「教程完成！即将进入第一关...」1s → GameScene 第一关
```

## 3. 关键实现

| 点 | 做法 |
|---|---|
| 复用正式系统 | `installCombat / installBuild / installRun` + 真弹反系统 + 真三选一（`RewardScene` 加 `resumeScene` 参数，选择后恢复教程场景） |
| 数据驱动 | 步骤顺序 / 文案 / 超时 / 敌人 / 卡牌 / 奖励 / 降级参数全部来自 `tutorial.json`，代码只留视觉常量 |
| 存档 | 教程进度写存档（`systems/TutorialProgress`），`SaveData` 通过模块增量加 `tutorial?: {completed, completedAt, skipped, lastStep}` |
| 往返安全 | 场景 SHUTDOWN 时 `bus.offAll(this)` + `clearRunScopedServices`；重开/换场景不残留弹反圈与监听器 |
| 失败兜底 | 玩家在教程里死亡 → 提示「满血复活」并以 `resumeStep` 重开当前步骤；三步内失败不会卡死 |
| 跳过 | 「[跳过教程]」→ 确认框「确定要跳过教程吗？」→ 跳过也写 `completed`，但不发 20 材料 |
| 调试入口 | `?scene=tutorial`；DEV 下 `window.__tutorial()` 返回只读快照（步骤、目标点、敌人、弹反窗口、存档等） |

## 4. 自动验收（`web/.tmp/acc-tutorial.mjs`，31 条断言全通过）

运行：先起 dev server（5199）→ `node web/.tmp/acc-tutorial.mjs http://127.0.0.1:5199/`

覆盖：进入教程 / 步骤 1 提示 / 真实 WASD 走到光圈 / 步骤 2 提示 / 真实鼠标左键击杀史莱姆 /
真实 Space 冲刺闪避成功 / 清怪弹出三选一（3 个选项）/ 按 1 选卡后卡槽 +1 且数值变化 /
冲锋兽蓄力出现窗口（120ms）/ 窗口内命中弹反 / 教程完成 / 自动进入第一关 /
存档 `tutorialCompleted=true` / 首次奖励 30→50 材料 / 跳过确认框 / 跳过后进第一关且不重复发奖 /
重开 3 次监听器不增长、无残留弹反圈。

其中「弹反窗口内命中」用页面内直接调用近战伤害管线（`combat.meleeArc`）保证 120ms 窗口可复现，
其余关键操作（移动 / 攻击 / 冲刺 / 选卡 / 跳过按钮）用真实键鼠事件驱动。
