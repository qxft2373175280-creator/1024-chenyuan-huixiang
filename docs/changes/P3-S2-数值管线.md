# P3-S2 数值管线

## 改动文件
- web/src/systems/CardSystem.ts（新增）

## 结算顺序
base → levelScaling → 锻造被动 → 卡牌 add → mul → set → 封顶 → flags/params 合并。

## 封顶表
- critChance ≤ 0.75
- lifesteal ≤ 0.30
- attackSpeed ≤ 5
- executeBelow ∈ [0, 0.5]
- projectileCount ∈ [1, 9]
- comboHits ∈ [1, 5]
- damage ≤ 200（§7.5）

## 卡池规则
默认解锁 / 锻造已解锁 → 适配「还有空卡槽的武器」类别并集（避免主手满槽时发出装不上的卡）→ 未装或 stackable；按 card.weight 无放回抽取，精英房 epic 权重 ×2。

## 失败原因
- 该武器不适用
- 卡槽已满
- 已装备同名卡牌

## 验收
- [x] 10 张卡装上前后 stats 对照表（自动化断言 + 卡面文案逐张检查）
- [x] add → mul → set 顺序正确（`web/.tmp/acc-p3.mjs`：手枪 7 +3 =10 → ×0.8 = 8.00，与 §7.3.2 一致）
- [x] 类别不符 / 卡槽满 / 重复卡都有明确 reason
