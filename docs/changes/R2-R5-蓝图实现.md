## 2. 数据结构（全部契约外增量 / 独立 JSON）

### 2.1 存档字段（`core/profile-contracts.ts` 给冻结的 `SaveData` 加可选字段）

```ts
interface SaveData {
  slot?: number; createdAt?: number; lastPlayedAt?: number;
  progress?: { currentStage: number; highestStage: number; clears: Record<string, number>; losses: number };
  loadout?: { primary: string; cards: string[] };
  guideSeen?: boolean;
}
```
- 旧档没有这些字段 → 读取处按默认值兜底（`readProgress` / `readLoadout` / `sanitizeSave`）。
- 未选槽位时（`?scene=game` 等调试入口）仍读写旧 key `aaa1024_save_v1`，保持既有自动化脚本可用。

### 2.2 三存档槽（`systems/SaveSlotStore.ts`）

- 存储键：`aaa1024.save.slot1 / slot2 / slot3`，另有 `aaa1024.activeSlot` 记录当前槽位。
- 首次启动若三个槽都空、且存在旧单存档 → 自动迁移到槽位 1（只做一次）。
- `listSlots()` 给标题/继续游戏/存档管理提供摘要（第几关 / 最高 / 材料 / 最后游玩 / 教程状态）。
- 导出：`aaa1024-slot<N>-YYYY-MM-DD.json`（含 `kind/version/exportedAt/save` 包装）。
- 导入：`validateImport()` 校验 JSON 结构、版本、字段、数值范围（材料 0~1e7、stats 非负）、
  武器/卡牌 id 必须真实存在；**先校验再确认再写入**，坏档直接拒绝且不动原存档。

### 2.3 关卡曲线（`data/stages.json`）

```json
"scaling": { "maxStage": 10, "hpPerStage": 0.18, "damagePerStage": 0.12,
  "countPer2Stage": 0.08, "speedPer3Stage": 0.04,
  "challenge": { "hpPerStage": 0.1, "damagePerStage": 0.06, "countPer2Stage": 0.05, "speedPer3Stage": 0.03 },
  "maxCountMultiplier": 1.8, "replayRewardMul": 0.6 }
```
- `/src/systems/StageService.ts` 按公式算倍率（`computeStageScaling`），第 11 关起进入挑战模式。
- 敌人：`Enemy.spawn` 时按倍率克隆 def（生命 / 接触伤害 / 攻击伤害 / 速度）；
  波次数量按 `count` 倍率四舍五入（有 `maxCountMultiplier` 上限）。
- 奖励：`rewardMul`（回放 = 0.6）作用于击杀掉落与结算材料。
- 进度：通关 → `clears[stage]+1`、`highestStage`、主线 `currentStage = max(current, stage+1)`；
  回放通关只加 `clears`；失败只加 `losses`。

### 2.4 主界面指引（`data/menu-guide.json`）

5 步：开始游戏 / 历史关卡 / 装备·卡牌 / 锻造台 / 存档管理；`guideSeen` 控制首次自动弹出，
「帮助 / 指引」可重看；跳过/看完都会落盘。

## 3. 场景与入口

| 场景 | 作用 |

| `ResultScene`（改） | 显示关卡名 + 回放标记、奖励折算、下一关 / 再打一次 / 返回主界面 |
