## 3. 挑战模式最小规则（P1-2）

| 行为 | 规则 | 数值来源 |
|---|---|---|
| 入口 | 主线通关第 10 关后，主界面开始按钮变为「挑战模式 第 11 层」 | `stages.json/labels.challenge` |
| 难度 | 沿用 `scaling` 公式 + `challenge` 段加成 | `stages.json/scaling.challenge` |
| 通关 | `challengeLevel += 1`；**不动主线 `currentStage`**；奖励材料 | `challenge.rewardMaterials = 40` |
| 失败 | 只累加 `losses`；不扣材料、不推进、不倒退 `challengeLevel`；结算不再叠加普通奖励 | 同上 |
| 结算 | 挑战奖励单独一行；主按钮变「下一层」 | `stages.json/ui.challengeRewardText / challengeNext` |
