## 1. 修掉的 bug

| 编号 | 问题 | 根因 | 修复 | 证据 |
|---|---|---|---|---|
| BUG-005 | `bus.offAll(ctx)` 实际是 `removeAllListeners()`，任一场景/HUD 清理会把**所有订阅**清空 | P1 早期实现偷懒 | `TypedEventBus` 记录 `{key, fn, ctx}`，`offAll(ctx)` 精确解绑，新增 `listenerCount()`；`clear()` 才全局清 | restart ×10 监听器恒为 17 |
| BUG-006 | 锻造被动「行囊」（开局金币 +30）从未生效 | `RunService.start()` 把金币写死 0 | 开局金币 = `player.json.startGold` + `save.passiveBonuses().startGold`，并 toast 提示 | 代码 + 全流程回归 |
| BUG-007 | 战斗内没有 BGM（只有主菜单有） | `GameScene` 从未调 `playBgm` | 进战斗播 `bgm_dungeon`，Boss 房切 `bgm_boss` | 代码 + 运行时日志 |
| BUG-008 | HUD 武器槽一开始显示「—」，要装过卡才出现名字 | P3 的 `create()` 不发 `weapon:state`（那时还没挂槽位），HUD 收不到首次状态 | HUD 在 `weapon:changed` 后用 `player/upgrade` 服务补一次状态 | 运行时读 HUD 文本：铁剑/手枪 |
| BUG-003 补 | `RoomSystem.destroy()` 在场景 SHUTDOWN 时 `walls.clear()` 抛 `undefined.size`（restart/切结算必现） | 物理组已随场景销毁 | `try/catch` 兜底 | restart ×10 无异常 |

## 3. 工具与自检

- `scripts/check-assets.mjs` 增加**生成覆盖检查**（DEV-019）：静态扫 `TextureFactory.ts` 引用的 `TEX_KEYS.*`，
  任何 `TEX_KEYS` 的「值」既没被生成、也不在 manifest 里 → 直接失败。
  反例验证：删掉 `ICON_HEAL` 的生成语句 → `✗ 以下 TEX_KEYS 既没有在 TextureFactory 里生成、也不在 manifest 里：ICON_HEAL(ui_icon_heal)`，退出码 1。
- 新增验收脚本 `web/.tmp/acc-stability.mjs`（重启/压测/性能）与 `web/.tmp/acc-ux.mjs`（菜单入口/新手提示/切武器/进化演出）。
