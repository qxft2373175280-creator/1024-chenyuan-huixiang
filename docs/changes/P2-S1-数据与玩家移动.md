## 3. 契约与数据变动
- 契约：**未改动任何必填字段**。为落地实现补了两处增量（不破坏 v1）：

  - `keys.ts` 增加 `SCENE_KEYS.SANDBOX` 与 `TEX_KEYS`（P2 训练场与固定贴图 key）。
- 数据：新增 `player.json`、`enemies.json`（数值 100% 抄 §9.3/§9.4，未自行平衡）。
