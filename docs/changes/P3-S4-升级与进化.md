# P3-S4 升级与进化

## 改动文件
- web/src/systems/UpgradeSystem.ts（新增）

## 经验曲线
- 直接读 weapons.json 的 expToLevel / expToEvolve，无代码内数值
- Lv3 后经验累计到 expToEvolve 即 canEvolve；不自动进化

## 进化流程
1. evolutionTarget = getWeaponDef(def.evolvesTo)
2. defId 替换、evolved=true、level=3、exp=0
3. recompute（cardSlots 读新 def，cardIds 原样保留）
4. 发 weapon:evolved + weapon:state，播 sfx_evolve

## UI 契约（方案 A）
清房三选一里出现 kind='weapon'、weaponId=进化目标 id 的 offer，标题以「进化·」开头。
applyReward 识别到 canEvolve 的当前武器时调用 evolve，而不是直接 equip。

## 验收
- [x] Lv1→2→3 与 JSON 一致
- [x] 满经验三选一出现进化选项
- [x] 进化后卡槽 +1、卡牌保留、剑气生效
- [x] weapon:evolved + sfx_evolve 触发

## 验收结果（2026-10-24 实跑）
- `acc-p3.mjs`：铁剑按 `expToLevel` 升到 Lv3；补满 `expToEvolve` 后 `canEvolve=true`；
  `evolve()` 后 `defId=flame_sword`、`cardSlots=4`、已装卡（长刃/旋风斩）保留、伤害 12 → 29。
- 进化选项：手枪满级满经验时 `drop.roomRewards()` 返回 `weapon:进化·双管手枪`；
  `applyReward` 走 `upgrade.evolve` 后主手变 `twin_pistol`（不是直接 equip 覆盖等级/卡牌）。
- 实战全流程（`acc-flow.mjs`）里清房三选一装的卡在后续房间仍生效，说明 `recompute` 与 `weapon:state` 正常。
