## 1. 本步目标

菜单 → 开局 → 三选一/结算占位 → 锻造台解锁 → 刷新仍在；音效可用、静音可保存。

## 3. 契约与数据变动

- 契约：无破坏性变动
- 数据：`SaveData` 默认值 `materials = 30`（首次存档赠送，保证评委第一局就能买一条解锁）

## 4. 验收结果

- [x] 首屏 ≤ 3s（本地），进度条真实推进
- [x] 存档：默认 30 材料；购买后刷新仍在；把 localStorage 改乱后仍能启动（`sanitizeSave` + `try/catch`）
- [x] 静音按钮生效并落盘；首次点击后 `AudioContext.resume()`（自动播放策略）
- [x] 锻造台 4 页签可切换；蓝图解锁扣除材料、前置校验、材料不足有 toast 原因
- [x] 图鉴：6 武器（3 进化形态未获得显示 ？？？）、10 卡牌（3 张显示「需蓝图解锁」）、5 敌人
- [x] 占位三选一/结算可点通并能回到主菜单
- [x] `?debug=assets`、`?scene=forge&tab=cards`、`?scene=game|reward|result` 均可直达
- 证据：headless Chrome 截图 8 张（menu / forge-weapons / forge-cards / forge-unlocks / game / reward / result / assets），控制台 0 报错
