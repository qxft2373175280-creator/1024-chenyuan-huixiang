# P3-S5 掉落与奖励

## 改动文件
- web/src/systems/DropSystem.ts（新增）

## 奖励池
- combat：2 卡 + 1 非卡
- elite：1 卡（epic 权重 ×2）+ 武器经验 + 材料
- treasure：1 卡 + 材料 + 回血
- shop：卡 / 回血 / 材料 / 武器经验（价格来自 economy.shop）
- boss：无三选一
- 卡池不足时用非卡补足；超出 rewardCount 时优先裁卡、保留非卡项；可进化时替换掉一个非卡项为「进化」
- 选卡结果只提示一次：成功沿用 installCard 的「已装备·X」，失败只发 1 次 card:rejected

## 经济口径
- 全部价格读 rooms.json.economy.shop
- 宝箱材料读 economy.materialChest
- 击杀掉落：gold=enemy.gold，material=rand<materialChance?1:0

## 失败原因
- 金币不足
- 卡槽已满
- 该武器不适用
- 已装备同名卡牌
- 目标武器不存在

## 验收
- [x] 3 个不同选项且至少 1 个非卡
- [x] 宝箱/商店价格正确
- [x] 六种 kind 都能应用（card/heal/material/weaponExp/weapon(进化)/gold 路径均走通）
- [x] 应用后武器/角色/资源立即变化
