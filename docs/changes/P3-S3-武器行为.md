# P3-S3 武器行为

## 改动文件
- web/src/systems/WeaponSystem.ts（新增）

## 三种行为
- melee：三段连击，第 3 段 arcDeg ×1.2、击退 ×1.5；comboWindowMs 620
- ranged：按 attackSpeed 连射，弹道数量/夹角读 stats
- elemental：count 发扩散弹，trail=true

## stats → DamageSpec
- damage → amount
- critChance / critMult → spec 同名字段
- poisonPerHit / poisonDurationMs → status{poison}
- executeBelow + params.executeMult → execute
- chain + params → chain
- lifesteal → lifesteal
- plague_burst + explodeRadius + params → deathBurst

## 卡牌改造落点
- 分裂弹/弹幕狂欢：projectileCount、spreadDeg
- 旋风斩：flags=[spin] → arcDeg=360、range=spinRadiusPx
- 长刃：rangeTiles → 扇形半径；魔焰剑剑气按 `rangeTiles / def.range` 等比延长 `lifeMs`
- 毒刃/处决/连锁/疫爆/嗜血/弱点瞄准：见 DamageSpec 映射
