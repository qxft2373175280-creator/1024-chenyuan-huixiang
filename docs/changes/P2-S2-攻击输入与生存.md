## 1. 本步目标
能打、能被打、能死；先用武器桩验证，不等 P3。

## 2. 改动文件

| 文件 | 类型 | 说明 |
|---|---|---|
| `web/src/entities/Player.ts` | 新增 | 鼠标瞄准、左键按住攻击、Q/1/2 切武器、Space 冲刺、受击无敌、死亡 |
| `web/src/stubs/StubWeaponService.ts` | 新增 | `// TODO(P3)` 最小武器桩：扇形近战 / 直线射击，仅用于 M1 自测 |

## 3. 契约与数据变动
- 契约：无改动。攻击输入走 `IWeaponService.tryAttack(inst, origin, aimRad, nowMs)`，P2 不实现武器行为。
- 数据：无新增字段；冲刺/无敌数值全部来自 `player.json`。

## 4. 验收结果
- [x] 左键**按住**持续攻击（每帧 `pointer.leftButtonDown()` → `tryAttack`，冷却由 P3 判定）
- [x] 冲刺：`dashSpeed 520` / `dashDurationMs 180` / `dashCooldownMs 1200` / `dashIFrameMs 200`，有残影（每 40ms 一张，220ms 淡出）
- [x] 冲刺期间 `applyDamage` 直接返回 0（无敌帧）；受击后 `hurtIFrameMs 700` 内同样免疫并闪烁
- [x] 受击：闪白 90ms + 击退（冲量 × 0.6，指数衰减 110ms）+ `sfx_player_hurt` + 120ms 轻震屏
- [x] 死亡：置 `alive=false`、停物理、碎裂、广播 `player:died`（P4 据此走失败流程）
- [x] 切武器广播 `weapon:changed`；`player:stats` 只在数值变化时发（不轮询、不每帧发）
- [x] `tsc --noEmit` 0 error
- [ ] **人工试玩**：手感类验收（跟手、无敌帧是否够用）需本地 `npm run dev`

- 影响：`Player` 是 P3（攻击发起）与 P4（HUD/结算）的共同依赖；`player:died` 是失败流程唯一入口。
- 回归：`npm run check`；训练场里连续冲刺确认能穿过喷吐者弹道；被打 3 次确认 700ms 内只掉一次血。
